- An interval with no fixed period, such as `prn`, reads as a zero duration (`ParseInterval` returns `0, nil`, zero meaning "no fixed interval") and has no number of doses a day: say so with an error (`dose: "prn" has no doses a day`), never with a number. **When:** a prescription form names no fixed period between doses and a stage must decide what it reads as or how many doses a day it has; not `q0h`, which this does not decide (hospital-demo#1 does). (https://github.com/sunfmin/hospital-demo/issues/3#issuecomment-6135545374)
- A gate that is red because of the base branch and not the PR, once the fix has landed on the base branch, is no reason to escalate: merge the base branch in, run the gate again, and go on. **When:** the failing checks are in code the PR does not touch and came in with the base branch, and the fix for them has already landed there; not while the base branch is still red. (https://github.com/sunfmin/hospital-demo/issues/8#issuecomment-6136330691)
