# The team

The roles this team names, each by the short name its workflows call it. A role is a repo; its
rules, skills and hooks are in that repo, and nothing of them is here.

```yaml
roles:
  {role}: {repo}
```

Every key of this file, and of a workflow and a patrol, is in `afkconvoy --help`. After each edit
run `afkconvoy check --dir .` here, until it exits 0.
