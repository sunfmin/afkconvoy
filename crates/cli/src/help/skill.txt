WHEN TO RUN IT

  Once for each agent of your own that is to learn of afkconvoy: it prints the skill
  file to install into it. The file says when to reach for afkconvoy, and
  sends the agent to `afkconvoy --help`. It repeats nothing the help says, so it has
  nothing to go stale: a newer release asks for no newer file.

  Where to put it, for Claude Code — for a user, on every project of theirs:

      mkdir -p ~/.claude/skills/afkconvoy
      afkconvoy skill > ~/.claude/skills/afkconvoy/SKILL.md

  and for a project, from its root, committed for everybody who works in it:

      mkdir -p .claude/skills/afkconvoy
      afkconvoy skill > .claude/skills/afkconvoy/SKILL.md

WHO RUNS IT

  Whoever sets an agent up: a human, or the agent a human is talking to. In any
  directory: it is asked nothing about a repo.

WHAT IT READS AND WRITES

  Nothing. The file is part of the binary, and it is printed: where it goes is yours to
  say, with a redirection as above.

WHAT IT ANSWERS

  The file's text and no JSON object: a frontmatter of `name` and `description`, as a
  Claude Code skill needs, and under it the one instruction. It exits 0.

  Errors: none of its own.

WHAT TRIPS YOU UP

  - It installs nothing. Printed to a terminal, the file is nowhere an agent reads it.
  - A worker needs none of it: a worker is told what to run by its prompt and its role.
  - The directory is named as the skill is: `afkconvoy`, holding `SKILL.md`.
